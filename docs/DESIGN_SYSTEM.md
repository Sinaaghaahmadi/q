# سیستم طراحی آسامیت

اصول طراحی محصول، توکن‌ها و کلاس‌های آماده. مرجع پیاده‌سازی: `src/app/globals.css`.

---

## ۱. تحقیق تلگرام — چه آموختیم و چه برداشتیم

پیش از طراحی، تلگرام از سه زاویه بررسی شد:

### تکنولوژی
- **پروتکل:** MTProto (باینری، سریع، رمزنگاری‌شده) + TDLib (کتابخانه C++ چندسکویی)
- **کلاینت‌های وب:** Telegram Web A با **React + TypeScript**، Telegram Web K با TypeScript؛ هر دو متن‌باز
- **اندروید:** بومی Java/Kotlin؛ دسکتاپ: C++/Qt
- **برداشت آسامیت:** استک وبِ مدرن مشابه Web A (React/TypeScript از طریق Next.js 16)، معماری SPA، و لایه بلادرنگ جداشدنی (Socket.io به‌جای MTProto — مقیاس ما را ساده‌تر پوشش می‌دهد).

### زبان طراحی
- ظاهر فلت و تمیز، بدون شلوغی؛ تمرکز مطلق روی محتوا
- حباب‌های پیام با گوشه‌های نامتقارن (گوشه کوچک سمت فرستنده)
- اسکرول‌بار بسیار نازک و کم‌رنگ
- وضعیت پیام: ✓ ارسال، ✓✓ تحویل، رنگی = خوانده‌شده
- انیمیشن‌های ۶۰fps کوتاه و معنادار (نه تزئینی)
- فهرست چت: آواتار رنگی با حروف اول، بج شمارنده، سنجاق
- فیلترها/پوشه‌های چت بالای فهرست

### آنچه آگاهانه متفاوت ساختیم
- هویت رنگی **teal/emerald** به‌جای آبی تلگرام (طبق پرامپت محصول، بدون Indigo/آبی)
- **گلاسمورفیسم + عمق سه‌بعدی** به‌جای فلتِ خالص — هویت متمایز آسامیت
- جلسات/کلاس/دستیار هوشمند که تلگرام ندارد (ترکیب با Google Meet)

## ۲. رنگ (OKLCH)

| توکن | روشن | تاریک |
|------|------|-------|
| `--primary` | `oklch(0.55 0.15 170)` | `oklch(0.65 0.16 170)` |
| `--asameet` | `#0d9488` | `#14b8a6` |
| `--asameet-light` | `#14b8a6` | `#2dd4bf` |
| `--asameet-dark` | `#0f766e` | `#0d9488` |
| `--background` | `oklch(0.985 0.005 170)` | `oklch(0.17 0.015 250)` |

- قاعده: **هیچ Indigo/آبی** مگر درخواست صریح؛ خطر = قرمز `--destructive`؛ موفقیت = emerald.
- حالت تاریک با کلاس `.dark` روی `<html>` (next-themes) — همه توکن‌ها بازتعریف می‌شوند.

## ۳. تایپوگرافی

- فونت: **Vazirmatn** (وزن‌های ۱۰۰/۳۰۰/۴۰۰/۵۰۰/۷۰۰/۹۰۰، WOFF2، `font-display: swap`)
- fallback: `system-ui, sans-serif`
- سلسله‌مراتب: تیترها `font-black`، بدنه `leading-7/8` برای خوانایی فارسی

## ۴. گلاسمورفیسم

| کلاس | کاربرد |
|------|--------|
| `.glass` | سطح شیشه‌ای پایه (blur 16px, saturate 180%) |
| `.glass-subtle` / `.glass-strong` | شفاف‌تر / مات‌تر |
| `.glass-card` | کارت با شعاع ۱۶px + hover لیفت |
| `.glass-nav` | نوار ناوبری چسبان |
| `.btn-glass` / `.btn-glass-primary` | دکمه‌ها با ripple |

## ۵. عمق سه‌بعدی

- `.icon-3d` — سایه چندلایه + scale/translateY روی hover
- `.icon-3d-wrap` — ظرف گرادیانی آیکون با سایه داخلی (حس شیشه محدب)
- `.card-3d` — پرسپکتیو + `rotateX` روی hover
- `.img-glow` — هاله teal دور تصاویر

## ۶. حرکت (Motion)

- Framer Motion: الگوهای `fadeUp`, `stagger`, `AnimatePresence` بین تب‌ها/نماها
- CSS: `.animate-gradient-x` (گرادیان متحرک)، `.animate-float`، `.animate-pulse-ring`، `.slide-in` (RTL/LTR-آگاه)، `typing-dot`
- قاعده: هر انیمیشن ≤ ۴۰۰ms مگر پس‌زمینه تزئینی؛ منحنی `cubic-bezier(0.2, 0.8, 0.2, 1)`

## ۷. الگوهای تلگرامی

- `.msg-bubble-own` / `.msg-bubble-other` — شعاع نامتقارن RTL/LTR-آگاه
- `.chat-bg` — پس‌زمینه نقطه‌ای ظریف گفت‌وگو
- اسکرول‌بار ۶px شفاف
- وضعیت پیام: `Check` / `CheckCheck` (خوانده = آبی روشن روی حباب خودی)

## ۸. RTL و بین‌المللی‌سازی

- ۵ زبان (fa پیش‌فرض، en, fr, de, ar) — `RTL_LOCALES = ['fa','ar']`
- همیشه `start/end` به‌جای `left/right`؛ آیکون‌های جهت‌دار با `rtl:-scale-x-100`
- اعداد فارسی/عربی با `toLocaleDigits`

## ۹. دسترسی‌پذیری

- تگ‌های معنایی (`main/header/nav/section/article/figure`)
- `aria-label` روی همه دکمه‌های آیکونی؛ `focus-glow` برای فوکوس کیبورد
- حداقل ۴۴px هدف لمسی؛ `sr-only` در موارد لازم

## ۱۰. لوگو

حباب گفت‌وگو (گرادیان teal→emerald، براقیت شیشه‌ای بالا) + قله «A» با نقطه بالای آن:
هم‌زمان **A** لاتین، **آ** فارسی (نقطه = مد)، و سیلوئت یک انسان.
فایل‌ها: `public/logo.svg` (مرجع)، PNG ها با `npm run icons` تولید می‌شوند.
