# Asa — سایت مادرِ گروه برنامه‌نویسی آ

یک صفحهٔ معرفی، نه یک محصول: چه می‌کنیم، چه ساخته‌ایم، و از کجا می‌شود
همکاری را شروع کرد. ساده، کم‌حرف، بی‌شتاب.

## اجرا

سایت ایستا است و به هیچ ابزار ساختی نیاز ندارد:

```bash
npx http-server asa/app -p 8099   # http://127.0.0.1:8099
```

استقرار روی Vercel: ریشه را `asa/app` بگذارید؛ `vercel.json` سرصفحه‌ها و
کش را دارد.

## ساختار

```
asa/
├── app/                     سایت
│   ├── index.html           صفحهٔ معرفی (تک‌صفحه)
│   ├── tickets.html         ورود با تلفن + وضعیت درخواست‌ها
│   ├── css/asa.css          تمام سبک‌ها؛ توکن‌ها بالای فایل
│   ├── js/asa.js            ورود تدریجی بخش‌ها و نوار بالا
│   ├── js/tickets.js        جریان تیکت
│   ├── fonts/               وزیرمتن (متغیر، self-hosted)
│   ├── icons/icon.svg       نشان
│   └── img/                 تصویر پروژه‌ها (jpg، برای وب)
├── exports/                 همان تصویرها، PNG با کیفیت کامل (۳۲۰۰×۲۰۰۰)
└── scripts/generate-project-images.mjs
```

## برند

- **رنگ:** کاغذِ گرم `#faf8f4`، مرکب `#0d1117`، و طلا `#a2864f` به‌عنوان تنها
  رنگ تأکید. طلا کم به‌کار می‌رود؛ همین کم‌بودن است که کار می‌کند.
- **قلم:** وزیرمتنِ متغیر، line-height ۱٫۷۵، اعداد `tabular-nums`.
- **نشان:** حرف آ/A با یک ضربهٔ پیوسته و دو خط طلایی — همان زبان ضربهٔ
  `docs/brand.md`: سر گرد، ضخامت ثابت، رنگ فقط از توکن‌ها.
- **تصویرسازی:** هر کارت خدمات یک صحنهٔ SVG روی یک ریگ واحد دارد — دیسک
  تینت‌دار، سایهٔ تماس بیضوی، میدان ۱۲۰×۱۲۰.
- **حرکت:** ورود تدریجی بخش‌ها، ترسیم نشان، و دو مدار که آرام می‌چرخند.
  همه زیر `prefers-reduced-motion` خاموش می‌شوند.
- **لحن:** جملهٔ کوتاه، بدون ادبیات اداری، بدون علامت تعجب. دکمه فعل است.

## تصویر پروژه‌ها

`node asa/scripts/generate-project-images.mjs` شش قاب می‌سازد و هم‌زمان در
`exports/` (PNG) و `app/img/` (JPEG) می‌نویسد.

| فایل                        | پروژه       | بخش              |
| --------------------------- | ----------- | ---------------- |
| `qeymat-01-tablou-nerkh`    | قیمت آنلاین | بخش توسعه        |
| `qeymat-02-tahlil-dade`     | قیمت آنلاین | بخش داده و تحلیل |
| `qeymat-03-hoosh-masnooei`  | قیمت آنلاین | بخش هوش مصنوعی   |
| `delbar-01-goftogoo`        | دلبر        | بخش توسعه        |
| `delbar-02-mahsool`         | دلبر        | بخش محصول        |
| `delbar-03-pashtibani`      | دلبر        | بخش پشتیبانی     |

هر قاب واترمارک برند را دو لایه دارد: امضای گوشه (نشان + `Asa` + نام بخش) و
یک الگوی مورب کم‌رنگ که در کل تصویر تکرار می‌شود، طوری‌که جدا کردنش از تصویر
ممکن نباشد.

> **نکته:** `delbarapp.online` و `qeymat.online` از این محیط در دسترس نیستند
> (اتصال reset می‌شود). بنابراین قاب‌ها بازسازیِ برندشدهٔ سطح واقعی هر محصول‌اند،
> نه اسکرین‌شات خام. وقتی سایت‌ها در دسترس باشند، همین اسکریپت می‌تواند
> `page.goto` را جای `setContent` بگذارد و همان قاب و همان واترمارک را روی
> اسکرین‌شات واقعی بنشاند.

## تیکت

`tickets.html` سه قدم دارد: شماره → کد → فهرست. نشست در `localStorage` می‌ماند،
پس کاربر با بازگشت دوباره همان وضعیت را می‌بیند.

فعلاً بدون سرور کار می‌کند: کد تأیید روی همان صفحه نشان داده می‌شود و تیکت‌ها
در مرورگر می‌مانند — یعنی داده بین دستگاه‌ها منتقل نمی‌شود. برای اتصال به
سرویس واقعی فقط چهار تابع `api.*` در `js/tickets.js` (`requestCode`, `verify`,
`list`, `create`) باید فراخوانی شبکه شوند؛ بقیهٔ صفحه دست‌نخورده می‌ماند.
